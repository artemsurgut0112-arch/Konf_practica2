# Dependency Visualizer - Вариант 19

Инструмент для визуализации графа зависимостей npm пакетов. Проект реализуется в рамках дисциплины "Конфигурационное управление".

## 📋 О проекте

Программа анализирует зависимости JavaScript пакетов из npm registry и предоставляет инструменты для их визуализации.

### 🎯 Выполненные этапы

- ✅ **Этап 1**: Минимальный прототип с конфигурацией
- ✅ **Этап 2**: Сбор данных о зависимостях
- 🔄 **Этап 3**: Основные операции (в разработке)
- 🔄 **Этап 4**: Дополнительные операции (в разработке)  
- 🔄 **Этап 5**: Визуализация (в разработке)

## 🚀 Быстрый старт

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/dependency-visualizer-19.git
cd dependency-visualizer-19

# Запуск с командной строки
python practica2.py react --repo https://registry.npmjs.org

# Запуск с CSV конфигурацией
python practica2.py

🎯 Параметры конфигурации
Обязательные параметры
package_name - имя анализируемого npm пакета

repo_url - URL npm registry (обычно https://registry.npmjs.org)

Дополнительные параметры
test_mode (-t) - тестовый режим (использует локальные данные)

output_file (-o) - имя выходного файла для графа

ascii_tree (-a) - вывод зависимостей в виде ASCII-дерева

max_depth (-d) - максимальная глубина анализа (по умолчанию: 10)
